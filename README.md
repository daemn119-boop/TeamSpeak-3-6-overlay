# TS6 Overlay

Оверлей для Windows 10/11 x64: показывает ники участников голосового канала TeamSpeak 6 или TeamSpeak 3 поверх рабочего стола и игр в оконном/безрамочном режиме. Говорящий подсвечивается.

Работает как обычное прозрачное окно «поверх всех». Ничего не внедряется в процессы игр, память не читается. Данные берутся только из локальных Remote Apps (TS6) или ClientQuery (TS3); в сеть программа ничего не отправляет.

## Установка
1. Скачать установщик из релиза.
2. Установить.

## Подключение к TeamSpeak 6
1. В TeamSpeak: **Настройки → Remote Apps** — включите и запомните порт (по умолчанию `5899`).
2. Запустите оверлей. При первом запуске откроется инструкция из двух шагов. Разрешение можно найти через колокольчик или в Настройки → Remote Apps; после подтверждения запроса откроются настройки.
3. Если порт другой, укажите его в настройках оверлея (раздел «Подключение»).
4. Подключитесь к серверу и зайдите в канал: ники появятся в оверлее.

Ключ API выдаёт сам TeamSpeak. Он хранится только в зашифрованном виде (Windows DPAPI). Если шифрование недоступно, ключ держится только в памяти, и разрешение придётся подтверждать при каждом запуске. При потере связи программа переподключается сама.

## Подключение к TeamSpeak 3
1. В TeamSpeak 3 откройте **Инструменты → Параметры → Дополнения → Плагины → ClientQuery**, включите плагин и разрешите локальное соединение.
2. Нажмите у ClientQuery кнопку **«Настройки»**, создайте API-ключ и добавьте его в поле «Ключ API TeamSpeak 3» во вкладке «Подключение» программы. Ключ хранится зашифрованным через Windows DPAPI.
3. Оставьте порт `25639`, если в TS3 не задан другой. В поле «Клиент TeamSpeak» выберите автоопределение или TeamSpeak 3.
4. Подключитесь к серверу и зайдите в голосовой канал. Оверлей показывает участников текущего канала и события начала/окончания речи.

Во вкладке «Подключение» кнопка **«Инструкция по подключению»** открывает скриншот с указателями и подробные шаги. Ключ можно скопировать из настроек ClientQuery и вставить кнопкой рядом с полем в TS3 Overlay.

В режиме автоопределения программа проверяет локальные API TS6 и TS3; если оба клиента подключены, предпочитает TS6. Оба подключения работают только к `127.0.0.1`.

## Окно настроек
Настройки разбиты на вкладки «Оверлей», «Положение», «Подключение», «Управление» и «О программе». Во вкладке «Оверлей» находятся все параметры оформления, режим показа статуса подключения и переключатель видимости оверлея. Слева — живое превью: тестовые участники по очереди начинают говорить и замолкают, чтобы было видно анимацию появления и исчезновения. Выбор режима находится во вкладке «Положение»; по умолчанию отображаются только говорящие. Во вкладке «Подключение» настраивается порт Remote Apps. Восемь шрифтов (включая Montserrat) включены в программу; лицензии и сведения об авторах лежат в assets/fonts. Изменения сохраняются автоматически, кнопка «Сохранить» делает это явно. «Показать тестовый оверлей» выводит пример поверх рабочего стола на 8 секунд, «Сбросить настройки» возвращает значения по умолчанию (разрешение TeamSpeak не затрагивается). Сведения об авторе и версии находятся во вкладке «О программе».

Инструкция показывается только при первом запуске (после прохождения запоминается). Дальше программа стартует свёрнутой в трей, а настройки открываются из меню значка или двойным щелчком по нему.

## Управление
- **Значок в трее** (двойной щелчок — настройки): показать/скрыть оверлей, заблокировать положение, настройки, выход. Цвет значка: зелёный — работает, жёлтый — ждёт разрешения, серый — нет связи.
- **Перемещение**: пока положение не заблокировано, оверлей обведён пунктиром — перетащите его мышью (положение станет «своим»). Либо выберите угол экрана в настройках.
- **Блокировка**: клики проходят сквозь окно, фокус у игры не забирается. Снять блокировку — в меню трея.
- **Горячая клавиша** показа/скрытия: по умолчанию `Ctrl+Shift+F9`, меняется в настройках.
- **Автозапуск** с Windows — переключатель в настройках.

Настройки лежат в `%APPDATA%\ts6-overlay\settings.json` и сохраняются между запусками.

## Статусы
Подключение… · Ожидание разрешения · Нет соединения с TeamSpeak (клиент не запущен, Remote Apps выключены или неверный порт) · Доступ не выдан · Не подключён голосовой канал. Текущий статус виден в подсказке значка трея, в окне настроек и в самом оверлее, пока он разблокирован.

## Известные ограничения
- **Эксклюзивный полноэкранный режим** не поддерживается: обычное окно не может быть показано поверх него. Нужен оконный или безрамочный режим игры.
- Если открыто несколько вкладок серверов, активной считается та, где вы последний раз входили в канал или меняли своё состояние (микрофон, динамики). Remote Apps не сообщает, какая вкладка видна сейчас.
- Протокол Remote Apps официально не документирован. Реализация основана на открытых проектах сообщества и проверена на имитации сервера. С настоящим клиентом TeamSpeak 6 на Windows сборка пока не проверялась; если формат сообщений изменится в новой бета-версии, возможны сбои.
- Античиты: оверлей не внедряется в игру, но гарантировать отсутствие претензий конкретного античита нельзя.
- В свойствах Windows указаны автор и название проекта; сборка не подписана цифровой подписью. Размер около 270 МБ в распакованном виде (внутри Electron).

## Сборка из исходников
Нужны Node.js 20+ и npm.
```
npm install
npm test        # тест протокола на поддельном сервере
npm start       # запуск (в Windows)
npm run dist    # сборка dist/TS6Overlay-win32-x64 (запускать можно и на Linux)
```
Устройство: `ts.js` — клиент TeamSpeak 6 Remote Apps, `ts3.js` — клиент TeamSpeak 3 ClientQuery, `main.js` — окна, трей, горячая клавиша и настройки, `render.js` — общая отрисовка плашек (оверлей и превью), `overlay.html` — оверлей, `settings.html` — настройки, `welcome.html` — инструкция первого запуска, `assets/` — ресурсы.
